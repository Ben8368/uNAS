# 风险与开放假设

本文件只登记尚未验证的外部不确定性；实现后有意保留的妥协进入 [TECH_DEBT.md](TECH_DEBT.md)。

## 分级与阻断

- **P0**：阻断条目中指定的 Gate，必须关闭、降级或由维护者明确接受。
- **P1**：不阻断指定 Gate，但会改变范围、体验、商店或发布边界。
- **P2**：后续增强风险。

风险优先级不等于立即阻断所有阶段；每项必须写清 `阻断 Gate`、负责人和证据。负责人未指定时由项目发起人在对应 Gate 评审承担决策责任。

## 活跃风险

### RISK-005（P0）：Image 首个真实闭环与保真边界未知

- **阻断 Gate：** G2-Core。
- **问题：** EXIF、颜色、透明度、像素预算和输出质量可能与 Demo 假设不同。
- **关闭证据：** SP-03 的输入分类、输出元数据/视觉对比、取消和资源阈值。

### RISK-013（P1）：流媒体分片与音视频合并链路尚未验证

- **阻断 Gate：** Media 模块 Gate。
- **问题：** HLS/DASH 播放清单解析、鉴权分片、Range/并发、初始化段、时间戳、音视频 mux 与输出容器尚未接入或验证。
- **影响：** 不能把 .m3u8/.mpd 当作普通 Chrome 下载；也不能承诺捕获到的独立音频/视频可以直接合并。
- **降级：** 当前只下载可直接访问的媒体文件 URL；播放清单与合并功能显示未接入。
- **关闭证据：** SP-06/SP-07 固定 HLS/DASH 与独立音视频夹具的下载、合并、播放性、取消、资源预算和清理证据。

### RISK-014（P0）：UniPass 融合的真实凭据路径与发布身份尚未全部验收

- **阻断 Gate：** UniPass/uNAS 公开发布 Gate；不阻断当前本地解包构建。
- **问题：** 单一 MV3 构建、AdBlock/Vault 代码和默认 MV3 E2E（40/40，0 skipped）已通过；但工具栏 `action.onClicked` 的真实系统手势、独立原版 UniPass 扩展与 uNAS 的人工视觉对照、真实 WebDAV 冲突恢复、UniPass 资源再分发许可和 uNAS 维护者签名 key/固定扩展 ID尚未完成。
- **控制：** 保留原 UniPass WebDAV 恢复路径和旧扩展回滚来源；不复制 storage/IndexedDB、不自动卸载旧扩展、不使用真实凭据；Playwright 测试明确跳过无法模拟 action 手势的场景。
- **关闭证据：** 隔离 Chrome Profile 的浅/深主题截图对比、工具栏真实点击打开/关闭/外部点击/Escape/SPA 测试、独立原版 UniPass 对照、合成账号填充、合成 WebDAV 服务冲突夹具、许可批准记录和维护者保管的签名 key 对应 manifest。当前 E2E 已提供 HTTPS 合成页、原版 DOM/CSS 浮层截图和浮层全部应用视图截图，但不关闭独立扩展和真实 action 手势缺口。

### RISK-006（P0）：ffmpeg.wasm、WebCodecs 与媒体范围未知

- **阻断 Gate：** Media 模块 Gate。
- **问题：** codec、容器、CSP、线程、包体、冷启动、内存和页面关闭行为尚未实测。
- **影响：** Media 是否进入 V1，以及只支持哪些短任务和输入规模。
- **关闭证据：** SP-06/SP-07 的固定夹具、播放验证、测量方法、取消与清理。
- **降级：** 只保留缩略图或最窄媒体操作，或延后 Media。

### RISK-007（P0）：ZIP/PDF 安全与正确性边界未知

- **阻断 Gate：** 对应 Archive/PDF 模块 Gate。
- **问题：** ZIP64、路径穿越、炸弹、PDF 字体/对象/加密和超大页面仍未验证。
- **关闭证据：** SP-04/SP-05 的负向夹具、资源预算、输出验证和不支持表。
- **当前控制：** 受限 ZIP 切片保持输入 50 MiB、200 项、单项 32 MiB、总展开 64 MiB；Worker CRC 验证后才写新同级目录。[SP-04-A](../benchmarks/sp-04/README.md#sp-04-a真实-worker-负向夹具) 已补限定损坏/路径/标记/声明超限拒绝与失败后恢复，并修复目录后代和名称别名漏检；[SP-04-B](../benchmarks/sp-04/README.md#sp-04-b预提交取消与暂存清理) 已补预提交取消、Files 窗口关闭和 Worker/owner 暂存清理证据；[SP-04-C](../benchmarks/sp-04/README.md#sp-04-c提交阶段受控写入失败与部分输出) 已补提交阶段第二文件受控写入失败、部分输出和后续新目录恢复证据。RISK-007 不关闭：不代表 ZIP64、真实资源压力、浏览器标签/进程关闭、原生目录、配额失败、原子提交或完整回滚安全已验收。

### RISK-008（P2）：Chrome Web Store 单一用途与权限审核

- **阻断 Gate：** 未来 Store Gate；不阻断本地 Demo、探针和 G5 本地交付。
- **问题：** 新标签页导航、Link App 和多类文件工具可能被审核为功能过宽；本地文件同样需要准确隐私披露。
- **影响：** 商店文案、功能分组、权限、上架和更新。
- **关闭证据：** 进入商店计划后形成用途叙述、权限清单、隐私政策、商店材料和预审记录。
- **控制：** 届时按官方 `CHROMEWEBSTORE.md` 模板从实际 manifest 与权威文档生成资料，见 [SP-08](DEVELOPMENT_BLUEPRINT.md#sp-08-packaging-与本地交付)；skill 生成文案不构成审核通过证据。
- **降级：** 收窄真实模块、让工具从属于本地文件工作区单一用途。

### RISK-009（P1）：许可证与再分发策略未确定

- **阻断 Gate：** 公开分发 Gate；不阻断本地 Demo、隔离探针和未公开的本地交付。
- **问题：** 仓库许可证、WASM/codec、字体、图标、壁纸和夹具来源尚未批准。
- **关闭证据：** 根 LICENSE、第三方清单、素材 provenance、哈希与发布审查。

### RISK-015（P0）：Music encrypted-container 来源与浏览器边界尚未验证

- **阻断 Gate：** Music Module Gate；不阻断 G2-Core、G3 或其他已规划模块。
- **问题：** `um/cli` `v0.2.12` 根项目为 MIT，但 Go 依赖、WASM、KGM v5 的 KGG 数据库、构建物 provenance 和授权夹具仍未完成逐项审查；Module Proxy 的 `@main` 快照与网页当前 `main` 提交不一致；QMC 还存在 MMKV/文件路径分支，不能直接当作浏览器能力。
- **当前事实：** 维护者已说明获得作者授权；源码已通过 Go Module Proxy 临时同步并固定 tag/SHA/checksum；维护者提供的 `um-web.extension.v1.10.8` 仅完成静态观察，未加载、未执行、未进入 Git。
- **控制：** 不提交源代码/构建物，不运行 Go CLI，不引入 Native Helper；所有真实测试只用用户明确有权处理的固定夹具；uNAS 路径禁止远程封面、元数据、密钥、账号和在线链接；依赖/资源许可证和来源未清前不公开分发。
- **关闭证据：** [SP-09](../benchmarks/sp-09/README.md) 补齐依赖许可证清单、KGM/QMC/NCM 夹具 manifest 与 SHA-256、Worker/WASM/CSP/内存/取消/清理结果、不支持表，并由维护者决定进入、降级或延后 Music Module Gate。
- **降级：** 只提供格式识别与能力提示；无法证明浏览器安全、正确或可再分发时，不支持真实处理。

### RISK-010（P1）：前端先行导致真实能力返工

- **阻断 Gate：** 不直接阻断；在 G2/G3 评审交互差异。
- **问题：** 文件权限、性能或输出限制可能迫使 Demo 流程调整。
- **控制：** UI 依赖 port/contract；mock 能力文案保守；每个探针记录需要替换的 scenario 和 UX 变化。

### RISK-011（P1）：品牌辨识与外观知识产权边界

- **阻断 Gate：** 公开分发前必须关闭；不阻断 Frontend Demo。
- **问题：** uNAS 已是正式名称，但可能被误解为传统 NAS 产品；macOS/iPadOS 风格也可能因资产、字体、图标或逐像素模仿产生混淆。
- **关闭证据：** 品牌定位文案、原创视觉审查、素材许可证和公开分发截图审查。

### RISK-012（P1）：文件管理、网址 App 与共享外观改版待主观确认

- **阻断 Gate：** 不阻断本地前端打磨；由维护者在本轮界面验收时确认，不改变已验收的 G1。
- **问题：** 目录搜索、排序、路径导航、网址 App、中性窗口表面及精简文案已有自动化验证，但视觉偏好、真实触控与浏览器缩放体验仍待维护者确认。
- **负责人：** 项目发起人。
- **关闭证据：** [本轮验收记录](archive/reviews/2026-09-08-ui.md)列出深浅主题、长名称和窄窗口截图场景；生成产物位于被 Git 忽略的 `apps/extension/test-results/extension-e2e/`。维护者结合截图与解包扩展人工走查给出确认。真实文件处理不在当前 UI 风险范围内。

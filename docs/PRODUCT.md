# 产品定义

## 1. 产品命题

uNAS 是一个以 Manifest V3 浏览器扩展交付的本地优先新标签页工作区。它用桌面级交互组织常用网址、本地文件和内置处理工具，让用户从新标签页启动 App、选择或拖入文件，并在浏览器内完成常见图片、媒体、PDF 与 ZIP 工作流。

一句话定位：

> 把导航页、本地文件工作区和媒体工具合并成一个可信、快速、可定制的浏览器桌面。

核心价值：

1. **每天可见**：新标签页是高频入口，导航、最近任务和文件工具位于同一桌面。
2. **本地优先**：文件默认不上传，处理路径、临时数据和输出位置可解释。
3. **桌面体验**：宽屏采用桌面与窗口层级，平板宽度采用触控优先的全屏 App 与 sheet。
4. **能力真实**：前端 Demo 可以先验证体验，但真实格式、性能和限制必须由能力探针与夹具证明。
5. **统一任务**：Image、Media、PDF、Archive 共享进度、取消、错误、导出和清理语义。

## 2. 产品形态

- 扩展是唯一产品运行时；不另建面向用户的托管 Web 应用，也不提供传统桌面程序。
- 首发目标浏览器是 Chrome；当前通过解包扩展和本地安装验证，不把 Chrome Web Store 上架作为 V1 交付条件。
- New Tab 承载轻量 Desktop Shell、搜索、网址导航、App 启动和任务摘要。
- Workspace 是扩展内可复用的工具页面，承载文件授权、复杂参数和长任务。
- Service Worker 只处理安装、点击、菜单、消息和 Workspace 复用，不承担长时间计算。
- 内置 App 随扩展打包；自定义 App 在 V1 中只是声明式 HTTPS 网址快捷方式。

详细运行边界见 [ARCHITECTURE.md](ARCHITECTURE.md)，App 语义见 [APP_CONTRACT.md](APP_CONTRACT.md)。

## 3. 目标用户与核心任务

### 首要用户

公开产品画像与开发验证对象分开：实际开放范围见 [CONTEXT](../CONTEXT.md)。私有预览优先服务维护者真实工作流，不为尚不存在的旧版用户保留兼容承诺；转向外部用户前重新评估支持窗口与升级/数据迁移方案，策略见 [ADR 0008](ADR/0008-private-preview-modern-chrome.md)。

- 希望把常用网站、最近文件和轻量工具放到一个新标签页中的桌面浏览器用户。
- 经常处理图片、短视频、PDF 或压缩包，但不想安装大型桌面套件的内容与运营人员。
- 重视文件不离开设备、需要离线或弱网完成轻量任务的用户。

### 核心任务

1. 打开新标签页，搜索或启动常用 Link/Tool App。
2. 选择、拖入或重新授权本地文件，在 Files 中查看来源和可用操作。
3. 用 Image/Media/PDF/Archive App 打开文件，设置参数并创建任务。
4. 在 Task Center 查看进度、取消、失败原因和导出结果。
5. 注册网址快捷方式并整理分组、Dock 和桌面布局。

## 4. App 模型

| 类型 | V1 示例 | 边界 |
| --- | --- | --- |
| System App | Desktop、Files、Task Center、Settings | 随扩展打包，提供系统级 UI |
| Tool App | Image、Media、PDF、Archive | 通过共享 contract 创建受控任务 |
| Link App | 用户自定义网址 | 只打开 HTTPS 页面，不读取文件、不执行远程代码 |

V1 不支持 iframe App、下载后执行的第三方插件、用户脚本或 App 商店。

## 5. 前端 Demo 范围

Gate G0 后先建设可交互 Demo，范围包括：

- New Tab Desktop、搜索、Dock、App 启动、窗口/全屏适配。
- Link App 的添加、编辑、删除、分组和非法 URL 状态。
- Files、Image、Media、PDF、Archive、Task Center、Settings 的完整 mock 流程。
- 空态、权限拒绝、资源超限、处理中、取消、失败和成功状态。
- Wide/Regular 布局、深浅主题、减少透明度、减少动态和键盘导航。

Demo 流程不读取真实文件、不执行真实转换、不申请宽权限；所有结果必须标记为模拟。Phase 2 的 SP-02 例外接入用户手势授权的目录 metadata 浏览：默认只读，用户在窗口顶部确认后才向浏览器请求 `readwrite` 授权；写入仅限直接子项的新建文件夹、固定内容 Markdown 文档和非递归删除，不读既有文件内容、不递归扫描、不覆盖或导出。证据与限制见 [SP-02](../benchmarks/sp-02/README.md)。详细规则见 [FRONTEND_GUIDE.md](FRONTEND_GUIDE.md)。

## 6. V1 真实能力候选

以下均为计划，需在前端 Demo 后通过扩展真机探针才能升级为产品承诺：

| 模块 | 候选能力 | 明确边界 |
| --- | --- | --- |
| Desktop | 新标签页、Dock、搜索、Link App、主题与布局 | 不替代操作系统桌面，不自动读取浏览历史 |
| Files | 文件/目录选择、拖入、最近文件摘要、重新授权、导出 | 不扫描整个磁盘，不保证句柄永久有效 |
| Image | PNG/JPEG/WebP 转换、缩放、质量压缩、批量导出 | 动图、RAW、HEIF/AVIF 后置验证 |
| Archive | ZIP 创建、列表、选择性解压、冲突处理 | V1 不承诺 RAR/7z/TAR、破解或损坏包修复 |
| PDF | 合并、拆分、旋转、图片转 PDF、页面转图片 | 不做 OCR、电子签名、内容级编辑和复杂表单 |
| Media | 音频提取、缩略图、GIF、短片段与少量常见容器转换 | 不承诺任意 codec、长视频、4K、DRM 或后台续跑 |
| Tasks | 队列、进度、取消、失败原因、结果验证和历史摘要 | 页面关闭后的真实任务不保证继续 |

真实接入顺序默认是 Files → Image → ZIP → PDF → Media；每个模块有独立能力 Gate，不让高风险媒体阻塞基础工作区。

## 7. 非目标

- 不构建通用 Web OS、完整 Finder/Explorer、时间线视频编辑器、Photoshop 或 Word 类编辑器。
- 不提供独立 Web/PWA、Electron/Tauri、Native Helper 或服务端处理作为 V1 兜底。
- 不执行自定义远程代码，不以 Link App 获得网页或本地文件权限。
- 不绕过 DRM、登录、CORS、站点条款、扩展商店政策或浏览器安全提示。
- 不在没有真实证据时承诺所有格式、所有浏览器、无限大小、桌面级性能或关闭页面后继续处理。
- 不为追求 macOS/iPadOS 外观而复制 Apple 资产或牺牲可读性、性能和原创品牌。

## 8. 体验原则

- New Tab 先快后全；engine、WASM 和大型工具资源只在启动 Tool App 后加载。
- 宽屏呈现桌面层级，平板宽度呈现触控优先层级；不伪装具体 Apple 设备。
- Liquid Glass 只用于导航、控制和临时浮层，内容区使用稳定表面。
- 每个不可用选项都说明原因和替代；不能测量的进度不伪造百分比。
- 输出覆盖默认禁止；用户明确选择替换时仍需使用可验证的安全提交策略。
- Mock 与真实能力在视觉、文案和构建信息中均可区分。

## 9. 隐私与商业边界

- 默认无账号、无文件上传、无行为遥测、无广告注入。
- Link App 配置和布局默认只保存在本机；是否使用浏览器同步需单独决定和披露。
- 上传、遥测、错误上报、云处理或 Native 能力必须新增数据流、保留策略和 ADR。
- 即使数据只在本地处理，公开发布前也必须完成隐私政策、权限说明和商店数据披露。

## 10. 成功判据

### Frontend Demo 候选

- 用户能从新标签页完成 App 启动、Link 管理、文件选择模拟、任务创建、取消和结果查看。
- Wide/Regular、键盘、触控、深浅主题和无障碍降级有明确证据。
- New Tab 首屏不包含 engine/WASM，所有模拟能力均有醒目标识。
- 维护者确认信息架构、视觉方向、文案和主流程。

### V1 发布候选

- 每项真实承诺能力都有固定夹具、扩展真机证据、资源阈值和失败路径。
- 权限拒绝、Worker 终止、页面关闭、配额不足和导出失败不产生假成功。
- 内置 App 使用统一 Task/Engine Contract，Link App 始终无本地文件能力。
- New Tab 启动、Workspace 复用、扩展升级和存储迁移经过目标浏览器验收。
- 最小权限、隐私边界、许可证、WASM 和素材来源可审计；本地安装、升级与卸载后果可验证。

## 11. 开放产品决策

- 对外开放时的 Chrome 支持窗口、验证 OS 和 Wide/Regular 参考视口；私有预览版本策略见 ADR 0008。
- V1 首个真实发布是否包含 PDF，Media 是否只提供一个最窄工作流。
- Link App、布局和任务历史是否启用浏览器同步，以及默认保留多久。
- 何时进入 Chrome Web Store，以及届时如何表述单一用途并组织权限申请；Edge、Firefox 和 Safari 不在首发承诺内。

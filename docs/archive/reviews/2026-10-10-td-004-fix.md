## 修复范围

## 🔴 修复的问题

### TD-004：AdBlock 顶层页面发送方策略宽于注释声明（已关闭）

**问题：** 顶层 HTTP(S) 页面的内容脚本发送方可发送任意 AdBlock 消息，包括 `pauseBlockingForSite`、`refreshBlockingSubscriptions` 等，与注释声明"web pages may only request cosmetic rules"不符。

**影响：** 被攻陷的内容脚本可暂停某站点拦截（虽然仍需通过本扩展 `sender.id` 校验）。

**修复：**
1. `apps/extension/src/platform/extension/sender-policy.ts`
   - 收紧 `isAdBlockSender` 逻辑：所有网页来源（顶层和子 frame）只接受精确 `getCosmeticRules` 请求
   - 更新注释明确说明策略边界

2. `apps/extension/src/platform/extension/router.test.ts`
   - 新增断言：顶层页面发送 `getBlockingStatus`、`pauseBlockingForSite`、`refreshBlockingSubscriptions` 均被拒绝
   - 补充测试覆盖：确保非 cosmetic 消息从网页来源被正确拒绝

3. `SECURITY.md`
   - 更新消息路由安全边界描述：明确网页来源（顶层和子 frame）权限

4. `docs/TECH_DEBT.md`
   - 移除 TD-004（已关闭）

5. `docs/archive/tech-debt/2026-10.md`
   - 新建归档，记录 TD-004 关闭信息

if (isWebPageSender(sender, extensionId, isCosmeticRulesRequest)) return true
